# 교토·오사카 일본어 회화 카드

여행 중 말이 안 나올 때 화면을 보여주면 통하는 **일본어 회화 카드 64문장**입니다.
공항·이동, 호텔, 식당·술집, 쇼핑·면세, 도움·긴급 5개 상황으로 나뉘어 있고,
문장마다 일본어 · 한글 발음 · TIP이 함께 있습니다. 긴급 연락처 카드(경찰·구급·영사관)도 들어 있습니다.

**웹에서 바로 보기 → https://minary19-tech.github.io/kyoto-osaka/**

휴대폰에서 열면 이런 것들이 됩니다.

- 🔊 **듣기** — 기기의 일본어 음성으로 문장을 읽어 줍니다.
- 👀 **크게 보기** — 상대방에게 화면을 크게 띄워 보여줄 수 있습니다.
- ☆ **즐겨찾기** — 자주 쓰는 문장만 모아 봅니다(이 브라우저에 저장).
- 상단 탭 / 각 섹션 끝의 **상황 이동** — 상황별로 바로 넘어갑니다. 스크롤해도 상단 탭은 위에 붙어 있습니다.

스크립트가 실행되지 않는 환경(미리보기 등)에서도 카드 내용은 그대로 보입니다.
